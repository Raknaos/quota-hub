# Quota.Hub — Plateforme de Revente & Routage API IA

Hub API intelligent pour développeurs et agents autonomes.
Tarifs jusqu'à -85% sous les grilles officielles, compatible OpenAI SDK.

## Caractéristiques
- **Design Glass Quota** : Thème sobre dégradé lilas/cyan, 140°, opacité variable.
- **Catalogue Modèles 2026** : GPT-6 Astra, GPT-5.6 Sol/Luna, DeepSeek V4 Flash, GLM-5.3, Gemini 3.8 Flash, Kimi K3, Tencent HY4, Qwen 3.8 Flash.
- **Console Développeur** : Génération de clés `sk-quota-live-...`, plafonds stricts et suivi de consommation.
- **Architecture de Déploiement** : Prêt pour hébergement Vercel + Supabase (PostgreSQL) + Edge Functions.
