Guide d'Intégration Standard OpenAI

Compatible à 100% avec les bibliothèques et logiciels existants.

1. cURL (Requête brute)

curl https://smartapi.cheap/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-sm-VOTRE_CLE" \
  -d '{
    "model": "autosmart-flash-1.0",
    "messages": [{"role": "user", "content": "Bonjour !"}],
    "stream": true
  }'

2. Python (SDK officiel OpenAI)

from openai import OpenAI

client = OpenAI(
    base_url="https://smartapi.cheap/v1",
    api_key="sk-sm-VOTRE_CLE"
)

response = client.chat.completions.create(
    model="autosmart-flash-1.0",
    messages=[{"role": "user", "content": "Explique le caching en 1 ligne."}],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
